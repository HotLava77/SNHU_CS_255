Project Summary
This project contains the system design for DriverPass, a driver training company that helps students prepare for their DMV driving test. The system allows students to take online practice tests, schedule driving lessons, and track their progress.

The Problem
Many students fail their driving tests because they don't have enough practice or good training materials. DriverPass solves this by offering:

Online practice tests
In-person driving lessons with instructors
Three different training packages to choose from
Easy online scheduling


What I Created
1. System Design Document
A complete technical design with UML diagrams showing how the system works:

Use Case Diagram - who uses the system and what they can do
Activity Diagrams - step-by-step workflows for scheduling and testing
Sequence Diagram - how different parts of the system communicate
Class Diagram - the structure of the system's database
Technical Requirements - what hardware and software is needed

2. Client Presentation
A PowerPoint presentation explaining the system design to the business owner in simple, non-technical language.

Key Features
For Students:

Create an account and choose a training package
Schedule driving lessons online
Take practice tests (if they have Package 3)
View their progress and test scores

For Staff:

Secretary can schedule appointments for students
IT Officer can reset passwords and manage accounts
Owner can view reports and track all system activity
Instructors can add notes after each lesson

System Features:

Cloud-based (no servers to manage)
Secure payment processing
Automatic updates from the DMV
Works on computers, tablets, and phones
